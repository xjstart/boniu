# 真实抖音页面发布前验收清单

日期：2026-09-22。用途：弥补合成页面自动回归无法覆盖真实抖音 DOM、音频、登录、直播、多显示器与系统会话的边界。每次准备发布时在目标 x64/x86 环境按需执行；涉及登录的步骤只使用测试账号，不在截图和日志中暴露 Cookie、手机号或令牌。

## 0. 自动验证前置

- [ ] `scripts/check-version.ps1` 通过。
- [ ] `scripts/test.ps1 -Platform x64` 全绿。
- [ ] `scripts/test.ps1 -Platform x86` 全绿。
- [ ] 候选 EXE 架构与 SHA-256 已记录，未用旧 `dist/` 文件冒充候选构建。

## 1. 普通视频与清爽模式

- [ ] 连续切换至少 20 条短视频，画面、声音和滚动正常。
- [ ] 原布局下评论、点赞、分享、收藏、头像等互动按钮可见并可点击。
- [ ] 清爽模式只隐藏装饰，不强制横屏/竖屏、不裁切视频、不根据素材尺寸改变窗口。
- [ ] 互动按钮仍覆盖在全宽视频区域右侧，没有额外黑色栏。
- [ ] 页面结构异常时回退原始布局并显示行内提示；“重新应用页面样式”可恢复。

## 2. 自动隐藏、老板键与恢复

- [ ] 鼠标短暂越过窗口边缘 18 个设计像素缓冲区时不会立刻误隐藏。
- [ ] 鼠标按住或拖动期间不会自动隐藏；释放并真正离开后按设置延迟隐藏。
- [ ] 点击评论、点赞、分享和登录控件不会因边缘竞速导致窗口抢先隐藏。
- [ ] `Ctrl+Alt+D` 隐藏立即生效，屏幕与任务栏无残留窗口或模态对话框。
- [ ] 恢复快捷键不可用但托盘可见时，失焦隐藏和鼠标移出隐藏仍可安全恢复。
- [ ] 快捷键和托盘都不可用时，不允许进入无法恢复的隐藏状态。

## 3. 音频、挂起与恢复

- [ ] 播放中隐藏后立即无声，没有短暂漏音。
- [ ] 隐藏约 10 秒后日志显示 WebView 挂起成功或可解释的重试。
- [ ] 恢复后仅恢复隐藏前正在播放的视频；用户手动暂停的视频不被强制播放。
- [ ] 快速连续显隐 20 次无黑屏、无旧暂停命令覆盖新恢复状态。
- [ ] 隐藏 30 分钟后恢复，页面仍可播放、滚动和互动。

## 4. 直播

- [ ] 直播 URL 和推荐页打开的直播弹层都能被识别。
- [ ] 开启自动横屏时进入直播切换横屏，退出直播恢复普通窗口位置与尺寸。
- [ ] 直播适配隐藏预期区域且播放器完整；退出直播后临时样式被移除。
- [ ] 聊天、礼物或登录弹层不会让老板键留下独立窗口。

## 5. 登录、数据与隐私

- [ ] 登录后重启仍保留登录状态。
- [ ] “清除登录和网页缓存”确认取消时不删除数据，确认后登录状态被清除。
- [ ] 普通设置保存与损坏设置回退正常。
- [ ] 日志、诊断文件和截图不包含 Cookie、令牌或网页存储正文。

## 6. Windows 与显示环境

- [ ] Windows 10 和 Windows 11 至少各验证一次；明确不在 Windows 7/8/8.1 上运行。
- [ ] 100%、125%、150%、200% DPI 下工具栏、设置页、圆角和缩放把手正常。
- [ ] 在不同 DPI 的双显示器之间拖动，窗口不越界、不跳到不可见区域。
- [ ] 锁屏、控制台断开和远程会话断开时窗口强制隐藏，解锁后可通过快捷键或托盘恢复。

## 7. 更新与回滚

- [ ] 检查更新只提示，不自动下载安装；第二次明确操作才开始安装。
- [ ] 断网、超时、哈希错误、正文中断和目录不可写均给出可操作提示且清理 `.part`。
- [ ] 更新前设置备份最多保留最近三份。
- [ ] 新版本健康启动后清理启动器 `.bak`；健康检查失败时旧启动器恢复。
- [ ] `%LOCALAPPDATA%/MiniViewWebView2/App/` 每个架构只保留当前版本和最近一个旧版本。

## 8. 30 分钟稳定性观察

- [ ] 真实推荐页连续播放 30 分钟，CPU、内存无持续单向异常增长。
- [ ] 期间执行显隐、设置往返、直播进入退出和多显示器迁移。
- [ ] 最后检查 `run.log`：没有未解释的 UI 长卡顿、异步异常或持续挂起失败。

## 9. 后台播放（2026-10-10 新增）

- [ ] 从“更多”菜单和设置均可进入无画面小窗；背景无视频残留、闪帧，声音继续，重新启动默认回普通模式。
- [ ] 连续前后切换至少 20 条；原生控件与方向键兼容路径均能切换，切到其他程序后全局快捷键有效且不抢焦点。
- [ ] 默认 Ctrl+Alt+Up / Down 可录入其他组合键、禁用和恢复默认；与已有快捷键或其他程序冲突时不保存并提示。
- [ ] 短视频自然结束自动下一条；网页自己连播时不重复跳过，连续快速点击也不连续误跳。
- [ ] 手动暂停后仍保持暂停；进入后台时的静音状态保留，静音按钮可恢复声音。
- [ ] 鼠标移出和切到其他程序不中断后台播放；老板键、立即隐藏、锁屏及会话断开仍立即暂停静音。
- [ ] 隐藏约 10 秒后仍沿用挂起和恢复逻辑；恢复后只显示后台控制窗，不突然露出画面，不强制播放手动暂停的视频。
- [ ] 推荐流刷到直播时，按钮和全局快捷键均可上一条、下一条；直播不自动下一条，不改变小窗为横屏。独立直播间显示返回推荐流的提示。
- [ ] 后台切换到直播或 canvas 画面时，不出现“没有视频”或因旧画面坐标误报超时；前台滚轮可切换的同一条目在后台也可离开。
- [ ] 新版登录遮罩显示时停止切换；关闭遮罩后可继续。原生切换无响应时备用滚轮仅尝试一次，不在恢复画面时补发积压切换。
- [ ] 后台音量 0%、35%、100% 均生效；换视频、直播、隐藏恢复和重新启动后保留音量。静音期间调节滑块不解除静音，手动暂停不被音量调节打断。
- [ ] 旧版 360×160 小窗位置加载后扩展到至少 200 高度；100%～200% DPI 下音量滑块与提示不遮挡按钮。
- [ ] 设置往返及普通/后台模式快速切换至少 20 次；恢复画面无黑屏，普通、直播和后台窗口尺寸互不覆盖。
- [ ] 100%、125%、150%、200% DPI 和双显示器下控制入口可见、文字可读、拖动及缩放正常。
- [ ] 无视频、登录弹窗、切换失效或网络中断时显示行内提示，可恢复画面处理；没有持续重复切换。
- [ ] 真实推荐页后台播放 30 分钟，自动下一条和声音持续有效；检查 CPU、内存和日志，无持续异常增长。

本节需真实抖音环境人工验收；离线回归通过不代表这些项目已通过。
